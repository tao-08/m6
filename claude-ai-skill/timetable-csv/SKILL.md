# タイムテーブル・名簿の画像 → 取り込み用 CSV

画像を読んで、取り込み画面がそのまま読める CSV を作る。**下の型を1文字も崩さないこと。**
取り込み側は見出しの文字で列を探すので、見出しの書き方を間違えると読めない。

## 手順

1. **画像を全部読む**。複数枚なら、同じ表の続き（2ページ目）か、別の日程・別の表かを見分ける
2. **種類を決める**
   - 時間・バンド名・曲数… の表 → **タイムテーブル**（1日分 = CSV 1本）
   - バンド名・Vo・Gt・Ba・Dr… の表 → **名簿**
   - 1枚に両方 → CSV を分ける
3. **型どおりに CSV を書く**（下の「タイムテーブルの型」「名簿の型」）
4. **検証する**：`python scripts/check_csv.py <CSV> [<CSV>...]`
   - ✖ / ⚠ が出たら直してもう一度。exit 0 になるまで終わらない
5. **渡す**：CSV をダウンロードできる場所に保存する（claude.ai なら `/mnt/user-data/outputs/`）。
   検証の出力（読めた枠の一覧）と、自信のない箇所の一覧をユーザーに見せる

## ファイルの形

- 文字コード **UTF-8（BOM付き）**。Excel で開いても化けないように BOM を付ける
- ファイル名：`<ライブ名><日程>_timetable.csv` / `<ライブ名>_roster.csv`（例 `12月ライブ1日目_timetable.csv`）
- カンマ・改行・`"` を含むセルは `"..."` で囲む（`"` は `""`）
- 読めない・自信のない文字は**推測で埋めない**。末尾に `?` を付けて書き（例 `山田太?`）、最後にユーザーへ一覧で聞く

## タイムテーブルの型

```
12月6日,,,12月ライブ1日目,,会場,下高井戸G-ROKS
時間,,持ち時間,バンド名,曲数,人数,key
10:00,,60,集合,,,
11:00,11:30,30,ELLEGARDEN（岩崎）,4,4,
11:30,12:00,30,BUMP OF CHICKEN,4,5,私物
12:00,12:10,10,転換,,,
18:00,18:30,30,SEKAI NO OWARI,4,7,私物/貸出（エレピ）
18:30,20:00,90,撤収,,,
```

- **1行目（前置き行）**：日付・タイトル・会場を書く
  - 日付は `12月6日` か `12/6`。**年は書かない**（取り込み画面で年を確認する）
  - タイトルは `〇〇ライブ1日目` の形。`日目` は 1〜3。`教室ライブ` もあり
  - 会場は `会場` のセルの**右隣**に会場名（または1セルで `会場：〇〇`）
  - 画像に無い情報は作らない。日付・タイトル・会場が無ければユーザーに聞く
- **見出し行**：`時間,,持ち時間,バンド名,曲数,人数,key`
  - `バンド名` と `時間` は**必須**（これが無いと取り込めない）
  - `時間` の右の**見出しが空の列**が「終了時刻」になる
- **データ行**
  - 時刻は半角 `HH:MM`。開始・終了の2列に分ける
  - 曲数・人数は数字だけ
  - `key` は鍵盤のメモ（`私物` `貸出（エレピ）` など）。無ければ空
  - 休憩・転換・撤収・リハ・準備・解散・打ち上げなど**バンドでない枠は、曲数・人数を空**にする
  - `集合` の行は書いてもいい（取り込みでは読み飛ばされる）
  - 空行は書かない
- **バンド名は画像の表記どおり**。全角・半角の揺れは取り込み側が吸収する
  - 同じバンドが2回出る日程は、画像どおり `ELLEGARDEN（岩崎）` のように括弧で代表者を付ける

## 名簿の型

```
バンド名,Vo(Gt.),Gt.1,Gt2,Ba.,Dr.,Key./その他,曲数
ヨルシカ,安田結衣,鈴木悠太,岩崎太一,宗像雄太,垰田圭吾,村田侑斗,4
04 Limited Sazabys,八木毬有,木村剛,郡山桃子,,煙山諒芽,,4
水中、それは苦しい,齋藤恭平,,,小坂千都乃,垰田圭吾,茂田井教崇(Vn),4
GOING UNDER GROUND,垰田圭吾,林佑晟,,奥山航太郎,小豆畑健吾、東哲平、福地龍之介,三澤優,3
```

- **見出し**：`バンド名` から `曲数` までの間がパートの列
  - パートの見出しは `Vo` `Gt` `Ba` `Dr` `Key` `その他`（`Cho` `Perc` も可）で**始める**。`Vo(Gt.)` `Gt.1` `Ba.` もOK
  - 画像の見出しをそのまま使ってよい。ただし上のどれかで始まっていること
- **名前の書き方**（取り込み側の区切りのルールに合わせる）
  - **姓と名の間に空白を入れない**（`井口 理` × → `井口理` ○）。空白は「別の人」の区切りとして読まれる
  - 1セルに2人以上いるときは `、` で区切る（`小豆畑健吾、東哲平`）
  - 空いているパートは**空セル**。`-` や `なし` も書かない
- **楽器が欄と違う人**：名前の後ろに半角括弧で楽器を付ける（`茂田井教崇(Vn)` `丸野友多郎(Sax)`）
  - Vo/Gt/Ba/Dr 以外の楽器（Vn・Sax・Perc…）の人は、画像で Gt 欄に書いてあっても **`Key./その他` 欄**に書く。埋まっていれば `、` で並べる
- **ボーカルが楽器も弾く**ときは、ボーカルの名前に楽器を付けてよい（`山田太郎(Gt)` = ギターボーカル）。
  画像に書いていなければ付けない（取り込み側が空いている欄から推測する）

## 画像を読むときの注意

- 表の外のメモ（「要修正」「変更あり」など）は CSV に入れない。気になるものは最後にユーザーへ伝える
- 取り消し線・手書きの修正があれば、修正後の方を採用し、ユーザーに確認する
- 2ページ以上ある表は、2ページ目の見出し行を書かずに続ける
