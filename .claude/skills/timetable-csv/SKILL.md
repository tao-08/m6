# タイムテーブル画像 → 取り込み用 CSV

`v3/import.php` は画像を読めない。画像を読んで、**`v3/lib/import/parsers.php` がそのまま食える CSV** を書くのがこのスキルの仕事。
パース処理は新しく書かない。取り込み側のルールに合わせた CSV を書くだけ。

## 手順

1. **画像を読む**：引数のパスを Read で開く（複数枚OK。2ページ目以降は同じ表の続きとして1本の CSV にまとめる）。
2. **種類を判断**：
   - 時間・バンド名・曲数… → **タイムテーブル**
   - バンド名・Vo・Gt・Ba・Dr… → **名簿（roster）**
   - 1枚に両方ある → CSV を2本に分ける
3. **CSV を書く**（下のテンプレ・ルール厳守）。
4. **検証**：
   ```
   C:/xampp/php/php -d xdebug.mode=off "<repo>/.claude/skills/timetable-csv/scripts/check_csv.php" <CSV> [<CSV>...]
   ```
   本物の取り込み処理（read_table_file → detect_table_kind → parse_*）に通した結果が出る。
   ✖ や ⚠ が出たら CSV を直して再実行。exit 0 になるまで終わらない。
5. **報告**：check_csv.php の出力（枠一覧）と、自信の無い箇所の一覧をユーザーに見せる。

## 出力先・形式

- 画像と同じフォルダに `<画像名>_timetable.csv` / `<画像名>_roster.csv`
- **UTF-8（BOM付き）**、改行 CRLF でも LF でも可。BOM を付けると Excel で開いても化けない
  - Write で書いたあと BOM を付ける：`printf '\xEF\xBB\xBF' | cat - a.csv > b.csv && mv b.csv a.csv`
- カンマ・改行・`"` を含むセルは `"..."` で囲む（`"` は `""` に）

## タイムテーブルのテンプレ

```
9月ライブ1日目,,,,,
9月20日,,会場,〇〇ホール,,
時間,,バンド名,曲数,人数,Key
12:30,,集合,,,
13:00,13:20,King Gnu,4,4,
13:20,13:30,転換,,,
13:30,13:50,ずっと真夜中でいいのに。,3,6,私物（シンセ）
```

ルール（取り込み側がこう読むから）：
- **見出し行に「バンド名」セルが必須**。これが無いと即エラー。見出しには `時間` も必須（これでタイムテーブルと判定される）
- 見出しより上が「前置き行」。ここから読むもの：
  - 日付：`9月20日` または `9/20`（**年は書かない・読まれない**）
  - 会場：`会場` の**右隣のセル**に会場名、または1セルに `会場：〇〇`
  - タイトル：`ライブ` か `日目` を含むセル。`〇〇ライブ2日目` → ライブ名「〇〇ライブ」＋日程「2日目」（1〜3日目のみ）。`教室ライブ` もOK
  - 画像にタイトル・日付・会場が無ければ、ユーザーに聞いてから書く（勝手に作らない）
- 時間：`時間` の右に**見出しが空の列**を置くと「開始, 終了」の2列として読まれる。時刻は半角 `HH:MM`
- 曲数・人数：数字だけ。`4(5)` のような書き方は最初の数字が使われる
- Key：鍵盤のメモ（私物・会場備品など）。無ければ空
- バンドでない枠（休憩・転換・撤収・リハ・準備・解散・打ち上げ など）は曲数・人数を**空**にする → 自動で「取り込まない」扱い
- `集合` の行は読み飛ばされる。書いても書かなくてもいい
- バンド名は画像の表記どおり（全角/半角の揺れは取り込み側が吸収する）

## 名簿（roster）のテンプレ

```
バンド名,Vo,Gt1,Gt2,Ba,Dr,Key,その他,曲数,人数
King Gnu,井口理,常田大希,,新井和輝,勢喜遊,,,4,4
```

ルール：
- 見出しは `バンド名` から `曲数` の間がパート列。見出しは Vo / Gt / Ba / Dr / Key / その他（Cho, Perc も可）で始める。`Vo(Gt.)` `Gt.1` もOK
- 見出しに Vo/Gt/Ba/Dr のどれかがあると名簿と判定される
- **名前の姓と名の間に空白を入れない**（`井口 理` ×→ `井口理` ○）。空白・`・` `、` `,` `/` `&` は「別の人」の区切りとして読まれる
- 1セルに2人いるときは `、` で区切る（`常田大希、井口理`）
- 空きパートは空セル。`未定` `募集` `なし` `-` は人として扱われない
- 補足パート（Sax など）は `丸野友多郎(Sax)` と括弧で名前にくっつける

## 読めない文字

- **推測で埋めない**。読めない・自信が無いセルは末尾に `?` を付けて書き（例：`山田太?`）、最後に「要確認」として行番号つきで一覧を出す
- ユーザーが答えたら `?` を消して再検証する
