# バンド希望の LINE 回答 + 名簿 → 集計用 CSV

集計（熱量・全員が下位）はサイトのバンド希望調査が計算する。**ここでは計算しない**。照合して CSV を作るだけ。

## 出す CSV の型

```
バンド,メンバー,順位
東京事変,山田,2
東京事変,佐藤,
```

- **名簿のメンバー全員**を1行ずつ書く（1人×1バンド = 1行）。未回答の人・回答に出てこなかったバンドは順位を空欄にする
- バンド名・メンバー名は**名簿の書き方そのまま**にする（回答の「セカオワ」→ 名簿の「SEKAI NO OWARI」）
- 同じ人は全バンドで**同じ名前**にする（名前で同じ人を見分けるため）
- 1人の順位は 1, 2, 3… の連番にする。抜けや重複があればそのまま書かずユーザーに聞く
- UTF-8（BOM付き）。ファイル名は `<ライブ名>_band_survey.csv`

## 手順

1. 名簿（画像・Excel・CSV）を読み、バンドとメンバーの一覧を作る
2. LINE の回答ごとに「誰の回答か」を名簿の名前に照合する（LINE の表示名とちがうことが多い）
3. 回答のバンド名を名簿のバンドに照合する（略称・表記ゆれ・番号だけの書き方を寄せる）
4. CSV を書く
5. **自信のない照合を一覧でユーザーに見せて確認する**（例: 「"171" → 171（Vo 山田）で合っている？」「LINE の "ゆう" は名簿の 佐藤優 ？」）。推測で埋めない
6. 名簿に入っていないバンドを答えた人・名簿のバンドを答えていない人も一覧で伝える

## 守ること

- 回答の中身（誰が何位にしたか）を CSV 以外に書き出さない。要約・感想も書かない
- 生データの CSV はリポジトリのフォルダに保存しない
