# 利用規約 改定 要件定義書（AbbeyRoad.online）

> この文書は、利用規約の本文を作成する AI への指示書です。
> 一緒に渡すもの：現行の `v3/terms.php`（利用規約）と `v3/privacy.php`（プライバシーポリシー）。

---

## 0. 作業の指示（作成する AI へ）

1. 現行の `terms.php` を土台に、この文書の「3. 決定事項」「4. 条項ごとの要件」をすべて満たす本文に書き直す。
2. **事実はこの文書と添付ファイルに書かれたものだけを使う。** 書かれていない機能・数字・運用（料金、年齢制限、保存日数など）を推測で足さない。足りない情報は本文に入れず、末尾に「確認事項」として列挙して返す。
3. `privacy.php` と矛盾させない。個人情報の取得・利用目的・外部送信・保存期間・退会後の扱いは **プライバシーポリシーに書き、規約からは参照するだけ**にする（二重に書くと食い違う）。
4. 出力は次の2つ。
   - `terms.php` の `<main>` 内の本文（HTML）。PHP の部分（`h(APP_NAME)`、`LEGAL_CONTACT` の差し込み、`render_header` / `render_footer`）は現行のまま残す
   - 変更点の一覧（現行版のどの条を、なぜ変えたか）と「確認事項」

## 1. サービスの概要

| 項目 | 内容 |
| --- | --- |
| 名称 | AbbeyRoad.online（本文では `h(APP_NAME)` で差し込む） |
| 内容 | 大学の軽音楽サークルのデータベースサイト。ライブ・バンド・出演者・セットリストの記録と、部員の活動を助ける道具 |
| 料金 | 無料。広告なし |
| 運営 | 個人（【運営者の氏名】）が運営し、サークルの部員が任意で協力する。**サークルの公式サービスではない** |
| 問い合わせ先 | contact@abbeyroad.online（`LEGAL_CONTACT`）。ログインできない人は問い合わせフォーム（ログイン不要）も使える |
| 公開範囲 | 規約・プライバシーポリシー・新規登録・ログイン・ログインできない人の問い合わせ以外は、原則ログインが必要 |
| Google 連携 | Google カレンダー連携あり。規約・ポリシーの URL は Google の OAuth 審査に提出済み（審査担当も読む） |

## 2. 機能と利用者

### 2.1 利用者の種類

| 種類 | できること（規約に関係するもの） |
| --- | --- |
| 一般（部員） | 閲覧、ライブ・バンド・曲・会場の情報の登録・編集、掲示板・コメント（匿名・名義の投稿あり）、TAB 譜・曲メモ・画像の投稿、日程調整、プロフィール、ゲームのランキング |
| 幹部 | 上記に加え、スタジオ割・タイムテーブル作成 |
| 管理者 | 上記に加え、ユーザー管理（権限変更・アカウント無効化・招待コード変更）、名簿の取り込み、メンバーの統合・削除、変更履歴の閲覧と復元、匿名投稿の本名表示（設定で切替）、問い合わせの受信 |
| アカウントのない人 | 共有リンクからスタジオ練習の要否に回答できる。問い合わせフォームを送れる |
| 情報だけ載っている人 | 名簿の取り込みにより、アカウントを持たない部員・OB/OG の氏名・入部年度・出演履歴が載る |

### 2.2 アカウント

- 新規登録は**招待コード（合言葉）を知っている人が自分で行う**（現行規約の「運営者がアカウントを発行した人」は事実と違うので直す）。
- 名前が一致するメンバーがいれば、そのメンバーに紐付く。別のアカウントに紐付き済みなら登録できない。
- 退会は運営者への連絡で行う。管理者はアカウントを無効化できる（投稿者名・履歴は残る）。

### 2.3 規約に関係する機能

| 機能 | 規約上の論点 |
| --- | --- |
| ライブ・バンド・セットリスト・出演履歴の記録 | 他の部員の情報を登録・編集できる。正確さは保証しない |
| 掲示板・コメント・お知らせ | 投稿者の責任、匿名投稿でも運営は投稿者を識別できる、違反投稿の削除 |
| TAB 譜・曲メモ・添付画像・練習プレイヤー（YouTube 動画に合わせて流れる） | 他人の楽曲の著作権 |
| ライブの写真・動画（Google ドライブのフォルダ・YouTube のリンクをバンドに割り当てる、添付画像） | 写っている人の肖像・プライバシー |
| セッティングシート | 会場から受け取った PDF に書き込んで作る |
| 日程調整・Google カレンダー / iCal 連携 | 外部サービスの規約、候補やカレンダー反映の正確さ |
| AI 機能（タイムテーブル・名簿の画像読み取り、BPM 推定、TAB の AI 作成、会場・スタジオ情報の AI 入力） | 結果に誤りがありうる |
| 楽曲検索（Spotify・iTunes・ウェブ検索） | 外部サービスの情報の正確さ |
| ゲーム（ブロックパズル）のランキング | 名前つきで表示される。不正な記録 |

## 3. 決定事項（運営者が決めたこと）

| # | 論点 | 決定 |
| --- | --- | --- |
| D1 | 運営者 | 個人（**実名を載せる**：【運営者の氏名】）が運営し、サークルの部員が任意で協力する。サークルの公式運営ではないことを明記 |
| D2 | 同意の取り方 | **「新規登録することで、利用規約とプライバシーポリシーに同意したものとします」**とする。チェックボックスは置かない。新規登録画面のボタンの近くにこの一文と両方へのリンクを出す（画面側の実装は別作業。規約本文にも同じ趣旨を書く） |
| D3 | 著作権（TAB 譜・曲メモ・練習プレイヤー等） | **部内の練習目的に限定**。ログインした部員だけが見る前提。内容の責任は投稿者。権利者から申し立てがあれば削除する |
| D4 | 肖像（写真・動画） | 載せる人は写っている人に配慮する。写っている人は**申し出れば削除・非表示にできる** |
| D5 | アカウントのない人の情報 | 本人は（アカウントがなくても）問い合わせから**訂正・非表示を申し出られる** |
| D6 | AI 機能 | 結果に誤りがありうる。利用者が確かめてから使う前提。運営者は正確さを保証しない |
| D7 | 権限者（幹部・管理者）の義務 | 権限で知った情報（匿名投稿の本名、名簿、変更履歴、問い合わせ内容など）を他に漏らさない・目的外に使わない |
| D8 | 利用停止 | 規約違反のとき、運営者は予告なく投稿の削除・アカウントの無効化ができる |
| D9 | 準拠法・裁判管轄 | **入れない** |

| 権限者の義務 | D7 | **新設** |
| 禁止事項 | 現行の5つ＋下の「4.1」 | 追加 |

### 4.1 禁止事項に足すもの

- 他人の楽曲・楽譜・歌詞・動画・写真等を、部内の練習目的を超えて転載・共有する行為
- 招待コード、共有リンク（スタジオ練習の回答等）、サイト内の情報を部外に広める行為
- 他の部員の個人情報・写真・動画を本人の意に反して外部に持ち出す行為
- 記録を故意に誤った内容へ書き換える・消す行為
- ゲームの記録を不正な方法で送る行為

## 5. 書き方のルール

- 対象は大学生。**平易な日本語**で、法律用語は必要最小限（「甲・乙」「本条第◯項」は使わない）。です・ます調。
- 用語は統一する：「本サービス」「運営者」「利用者」「投稿」「管理者」「幹部」。
- 現行版と同じく `<h2>` で条、`<ol>`/`<ul>` で項目。新しい CSS クラスは作らない。
- 実在しない機能・運用を書かない（例：有料プラン、年齢確認、自動削除の日数）。
- 個人情報の具体的な扱いは書かず「プライバシーポリシーのとおり」と参照する。

## 6. 対象外

- プライバシーポリシーの改定（必要な点があれば「確認事項」で指摘だけする）
- 新規登録画面の文言・リンクの実装（D2 は本文の要件として扱う）
- 準拠法・裁判管轄（D9）
